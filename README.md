# Seguros Mile Toro 🛡️

Insurance advisory website for Milena Toro, an independent 
agent backed by Seguros Sura — one of Colombia's leading 
insurance companies. Based in Medellín, Colombia.

## 🔗 Live Site
[miletoroseguros.vercel.app](https://miletoroseguros.vercel.app)

## 🛠️ Built With
- Next.js
- React
- SCSS Modules

## ✨ Features
- Fully responsive design
- SEO optimized with structured data
- Multi-page site with 12+ insurance solution pages
- Personal and business insurance solutions showcase
- Dynamic health & wellness blog powered by external news API
- Direct WhatsApp contact integration
- Express payment link to Seguros Sura portal
- Social media integration (Instagram & Facebook)

## 🔌 API Integration
- **Salud y Bienestar**: Health and wellness articles fetched 
  automatically from an external news API — content stays 
  fresh without manual updates
